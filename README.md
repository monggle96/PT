# PT 급여계산기

트레이너용 세션 기록·급여 정산 웹앱. 모든 데이터는 사용자의 브라우저에만 저장되며 서버로 전송되지 않는다.

## 기능

- 달력 형태의 수업 스케줄 기록 (진행 / 취소 / 서비스 세션 구분)
- 회원 등록 회차를 소진 순서대로 차감하며 계약별 단가 자동 적용
- 매출 구간별 세션 요율, 정액·정률 인센티브
- 프리랜서 3.3% 또는 4대보험 공제 선택
- 매출 건별 실적 포함 여부 설정
- 백업 파일 내보내기·불러오기

## 깃허브 페이지로 올리기

1. 깃허브에서 새 저장소를 만든다. Public으로 설정한다.
2. 이 폴더의 파일 네 개를 저장소 루트에 그대로 올린다.
   - `index.html`
   - `manifest.webmanifest`
   - `sw.js`
   - `icon.png`
3. 저장소의 Settings → Pages로 간다.
4. Source를 `Deploy from a branch`로, Branch를 `main` / `/ (root)`로 지정하고 저장한다.
5. 1~2분 뒤 `https://<계정명>.github.io/<저장소명>/` 주소로 열린다.

## 홈 화면에 추가

아이폰은 사파리로 주소를 열고 공유 버튼 → 홈 화면에 추가.
안드로이드는 크롬 메뉴 → 앱 설치 또는 홈 화면에 추가.

추가한 앱은 주소창 없이 전체 화면으로 열리고 오프라인에서도 동작한다.

## 주의

브라우저 저장소는 영구 보관용이 아니다. 기기 저장 공간이 부족하거나 브라우저 데이터를 지우면 기록이 사라진다. 설정 탭에서 주기적으로 파일 백업을 내보내 둘 것.

아이폰에서는 사파리 탭과 홈 화면 앱의 저장 공간이 분리된다. 사파리에서 쓰던 기록을 홈 화면 앱으로 옮기려면 파일로 내보낸 뒤 홈 화면 앱에서 불러와야 한다.

## 앱을 수정한 뒤

`index.html`을 고쳐 다시 올릴 때는 `sw.js`의 `VERSION` 값도 함께 바꿔야 한다. 그러지 않으면 기존 사용자 기기에 캐시된 옛 버전이 계속 열린다.
